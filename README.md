# Movie-Recommendation-KNN

## Overview

This project implements a movie recommendation system using the K-Nearest Neighbors (KNN) algorithm. The system uses user-movie ratings from the MovieLens dataset to identify movies with similar rating patterns and recommend movies based on user preferences.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- KNN
- MovieLens Dataset

## Features

- Select a movie
- Find similar movies using KNN
- Get movie recommendations
